# FitBuddy: AI Fitness Plan Generator using Gemini Models

FitBuddy is a full-stack personal fitness application built with Python FastAPI and Tailwind CSS. It creates customized workout regimens, exercise descriptions, and nutrition tips tailored to individual user goals, body metrics, and equipment availability using Google's **Gemini models**.
